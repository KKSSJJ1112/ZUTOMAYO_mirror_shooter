## English

### ZUTOMAYO Mirror Shooter (DIY Replica)

A handmade replica of the mirror shooter prop featured in music videos and live performances by the Japanese J-pop band **ZUTOMAYO** (ずっと真夜中でいいのに。).

This pistol-shaped prop features LED illumination and a laser emitter at the muzzle.

### Features

- 3300mAh lithium-ion battery system
- Modular case design (assembly/disassembly capable)
- 3D printed enclosure
- Reprogrammable (color customization, etc.)
- Physical trigger switch for laser on/off mode toggle

### Components

| Part | Specification |
|------|---------------|
| PCB | Custom designed in KiCad, hand-soldered |
| MCU | ESP32-C3 Super Mini |
| LED Strip | NeoPixel (WS2812B) |
| Slide LED Ring | NeoPixel |
| Battery | Samsung SDI 18650 Li-ion cell |

### Project Structure

```
├── mirror/              # ESP32 PlatformIO project files
├── mirror_Shooter_v2/   # KiCad project files
└── mirrorshooter_stl/   # 3D printable STL files
```

## 日本語

### ずっと真夜中でいいのに。ミラーシューター（自作レプリカ）

日本のJ-popバンド「**ずっと真夜中でいいのに。**」（以下、ずとまよ）のMVやライブに登場するミラーシューターを自作しました。

拳銃型の小道具で、LEDによる発光と銃口部分からのレーザー照射が特徴です。

### 主な特徴

- 3300mAhリチウムイオンバッテリーシステム
- 組み立て・分解可能なケース構造
- 3Dプリント製ケース
- 再プログラミング可能（カラー変更など）
- トリガーの物理プッシュスイッチによるレーザーON/OFFモード切替

### 構成部品

| 部品 | 仕様 |
|------|------|
| PCB | KiCadで設計、手はんだ実装 |
| MCU | ESP32-C3 Super Mini |
| LEDストリップ | NeoPixel（WS2812B） |
| スライド背面LEDリング | NeoPixel |
| バッテリー | Samsung SDI 18650 リチウムイオンセル |

### プロジェクト構成

## 한국어

### 계속 한밤중이면 좋을텐데 미러슈터 (자작)

일본의 J-pop 밴드 **계속 한밤중이면 좋을텐데**(ずっと真夜中でいいのに。, 이하 즈토마요)의 MV 및 라이브에 등장하는 미러슈터를 제작했습니다.

권총형 소품으로, LED를 통한 발광과 총구 부분에서의 레이저가 특징입니다.

### 주요 특징

- 3300mAh 리튬 이온 배터리 시스템
- 조립 및 분해 가능한 케이스 구조
- 3D 프린팅 케이스
- 추후 재프로그래밍 가능 (색상 변경 등)
- 트리거의 물리 푸시 스위치를 통한 레이저 ON/OFF 모드 변경

### 구성 부품

| 부품 | 사양 |
|------|------|
| PCB | KiCad 설계, 핸드 솔더링 |
| MCU | ESP32-C3 Super Mini |
| LED 스트립 | NeoPixel (WS2812B) |
| 슬라이드 후면 LED 링 | NeoPixel |
| 배터리 | Samsung SDI 18650 리튬이온 셀 |

### 프로젝트 구조

```
├── mirror/              # ESP32 PlatformIO 프로젝트 파일
├── mirror_Shooter_v2/   # KiCad 프로젝트 파일
└── mirrorshooter_stl/   # 3D 프린팅용 STL 파일
```
